# Milestone 06 — Real thread matching

**Status:** Not started
**Estimated effort:** 8–12 development days after catalog approval

## Objective

Replace arbitrary hex-only colors with real, purchasable thread references and
a usable materials estimate.

## Deliverables

- [ ] Confirm permitted data source and usage terms for the first catalog
- [ ] Define a catalog-neutral thread data model
- [ ] Use perceptual color matching rather than raw RGB distance
- [ ] Show brand, number, name, approximation, and stitch count
- [ ] Let users replace an automatically selected thread
- [ ] Estimate quantities with documented coverage assumptions
- [ ] Preserve original generated colors when switching catalogs
- [ ] Add color-matching regression fixtures
- [ ] Publish a thread-matching feature page and methodology guide

## Acceptance criteria

- Matching is deterministic and covered by representative color fixtures.
- Catalog licensing or permission is documented in the repository.
- The UI clearly states that screen colors are approximations.
- Quantity estimates disclose assumptions and round conservatively.
