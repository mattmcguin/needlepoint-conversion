# Milestone 05 — Stitch-ready printable PDF

**Status:** Not started
**Estimated effort:** 7–10 development days

## Objective

Produce a printable pattern that someone can confidently stitch from without a
spreadsheet or manual image scaling.

## Deliverables

- [ ] Letter and A4 page sizes
- [ ] Cover preview and project metadata
- [ ] Paginated chart with row and column numbers
- [ ] Bold major grid lines every 10 stitches
- [ ] Color-independent stitch symbols
- [ ] Legend and stitch quantities
- [ ] Page overlap and alignment markers
- [ ] Print-scale verification fixtures
- [ ] Accessible preview before download
- [ ] Printable-pattern feature page and printing guide
- [ ] Sample PDF available to visitors

## Acceptance criteria

- A test grid printed at 100% scale matches its stated physical dimensions.
- Symbols remain distinguishable in grayscale.
- Every stitch appears exactly once in the authoritative page region.
- Large projects paginate without clipped rows, columns, legends, or labels.
