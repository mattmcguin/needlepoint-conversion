Help and support

Get back to making your pattern

Most issues come from an incompatible image, browser storage, or a blocked download. These checks solve the common problems without sending your photo anywhere.

The photo does not open

Try a JPG, PNG, or WebP file first. Some browsers can display HEIC photos but cannot process them through the same image tools. Exporting the photo as JPG from the phone's photo editor usually resolves that problem.

The pattern looks stretched

Use a crop that matches the intended project shape and keep Lock aspect ratio selected. Presets that would noticeably distort the image are disabled after a photo is chosen. Custom dimensions are available when the final shape is unusual.

The pattern has too many scattered colors

Lower Maximum colors, crop closer, or simplify the source background. The photo-preparation guide explains which image changes produce a cleaner chart.

A saved project disappeared

Projects are stored only in the browser where they were created. Private browsing, clearing site data, changing browsers, or using another device will make that local project unavailable. Cloud sync is not currently part of the product.

An export did not download

Allow downloads for needlepointmaker.com and try again. The grid image can be larger than the preview, so give the browser a moment to create it. If a button still fails, include the export type and device class in a feedback message.

Report a problem

Use the feedback form to describe the step, canvas dimensions, mesh, and general image type. Do not include the source photo or filename. An email is optional and is used only if you explicitly allow a follow-up.

Supporting the project

Needlepoint Maker remains free while product outcomes and feature demand are measured. An optional contribution link is planned for a later release; no payment is required to use the converter, guides, calculator, project saving, or exports.
