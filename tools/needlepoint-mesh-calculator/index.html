How the needlepoint size calculation works

Divide the number of stitches by the canvas mesh. A design that is 72 stitches wide on 18-mesh canvas is 72 ÷ 18, or 4 inches wide. The same 72-stitch chart on 13 mesh finishes at about 5.5 inches wide because each stitch occupies more space.

Formula: stitches ÷ mesh count = finished inches. Calculate width and height separately.

Finished design size is not the canvas cut size

The calculation describes the stitched area. You still need unstitched canvas around it so the piece can be held, blocked, and finished. A practical starting point is 2 inches on every side, which adds 4 inches to both the finished width and finished height. Your finisher or project type may call for a different allowance.

Choosing between size and detail

Changing mesh does not change the number of squares in the chart. It changes how tightly those squares fit into an inch. A higher mesh count makes the same chart smaller and allows finer detail; a lower mesh count makes it larger and is often easier to see and faster to stitch.

Needlepoint Maker currently creates patterns for 13 and 18 mesh. Use the calculator for other charted designs, then read the mesh-size guide before choosing canvas and thread.
